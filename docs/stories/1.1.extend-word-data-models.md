# Story 1.1: Extend Word Data Models for Multiple Definitions

## Status
Draft

## Story

**As a** developer,
**I want** to update word data structures to support multiple definitions,
**so that** both CEFR and WordsAPI words can store and access multiple meanings.

## Acceptance Criteria

1. Word database schema supports array of definitions with metadata (source, part of speech, example)
2. CEFR word models accommodate multiple definition entries while maintaining existing functionality
3. WordsAPI response parsing extracts and stores all available definitions from API responses
4. Data migration preserves existing single-definition words while enabling multiple-definition support
5. TypeScript interfaces updated to reflect new data structures across all components

### Data Models
**Current Database Schema** [Source: services/database.ts:81-97]:
- `word_details` table currently stores single definition per word with foreign key to `cefr_words`
- `external_words` table stores definitions as JSON string (line 142)
- Current structure: `definitions TEXT` stores JSON array but components access only first element

**Required Schema Updates**:
- Enhance `word_details.definition` to support structured JSON with metadata
- Add definition metadata fields: source, part_of_speech, example, confidence_score
- Maintain backward compatibility with existing single definition access patterns

### API Specifications
**WordsAPI Integration** [Source: services/wordsApiService.ts:6-27]:
- Current `WordsApiDefinition` interface supports: definition, partOfSpeech, synonyms, antonyms, derivation, examples
- `transformApiResponse` method (line 536) currently extracts only first definition for UI display
- Need to enhance parsing to capture all definitions with metadata preservation

### Component Specifications
**ReviewSection Component** [Source: components/ReviewSection.tsx:34-59]:
- Current `detailData` state supports single definition display in modal
- Word detail modal structure needs enhancement for multiple definitions
- Existing UI shows: definition, pronunciation, example, synonyms, antonyms
- Components expect single definition string in current implementation
